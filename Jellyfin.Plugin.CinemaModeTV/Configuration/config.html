Cinema Mode TV

Help

This plugin enables Jellyfin's Cinema Mode functionality to play intro content before Movies AND TV Shows. The plugin supports three types of intros: Trailer Pre-Rolls, Trailers, and Feature Pre-Rolls. Each can be configured/turned off below. All of this can be disabled at the user level by turning off Cinema Mode in the user's Playback settings. Pro-tip: Skip any pre-roll or trailer by pressing the next button in the player.

Playback Order: Trailer Pre-Roll → Trailers → Feature Pre-Roll → Your Movie/TV Show

Content Types
Play pre-rolls and trailers before movies.
Play pre-rolls and trailers before TV show episodes.

Trailer Pre-Rolls
0
Library containing media to play before a block of trailers. Setting this to "-" will disable this section.

Selection Rules

Ignore any pre-roll that has a seasonal tag not currently in season.
Pre-Roll's assigned a rating will not be selected if it exceeds the feature's rating. Pre-Roll's not assigned a rating are considered suitable for all features.

Trailers
The number of trailers to play before movies. Setting to 0 will turn this off.
The number of trailers to play before TV show episodes. Setting to 0 will turn this off.

Selection Rules

Consume mode plays only one trailer from a selection rule before moving to the next.
Ensures the rating of the trailer content does not exceed that of the feature (i.e. trailers for an "R" rated movie will not be shown before a "PG-13" movie). This setting will cause any unrated content to have no trailers played prior and not be shown as a trailer. In this case unrated refers to any content where the "Parental Rating" meta data field is marked "Unrated" or left blank.

Feature Pre-Rolls
0
Library containing media to play right before the feature. Setting this to "-" will disable this section.

Selection Rules

Ignore any pre-roll that has a seasonal tag not currently in season.
Pre-Roll's assigned a rating will not be selected if it exceeds the features rating. Pre-Roll's not assigned a rating are considered suitable for all features.
